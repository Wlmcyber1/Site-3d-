# 🚀 MDev - Email for Developers

Uma **Landing Page moderna e responsiva** desenvolvida para simular uma plataforma de serviços de e-mail voltada para desenvolvedores.  
O projeto foca em uma interface futurista em **Dark Mode**, com elementos 3D e animações fluidas.

---

## ✨ Demonstração Visual
- **Paleta de Cores**: Fundo Dark (#000000) com detalhes em cinza e roxo.  
- **Glassmorphism**: Camadas com desfoque e gradientes para efeito de vidro.  
- **Interatividade**: Botões com efeitos de *hover* e animações de entrada.  
- **3D Futurista**: Modelo interativo de robô integrado via Spline.  

---

## 🛠️ Tecnologias Utilizadas
- **HTML5 & CSS3** → Estruturação e estilização avançada (Flexbox, Keyframes).  
- **Spline** → Integração de modelo 3D interativo diretamente no navegador.  
- **AOS (Animate On Scroll)** → Animações de surgimento conforme rolagem da página.  
- **Google Fonts** → Tipografia moderna e limpa via *system-ui*.  

---

## 📂 Estrutura de Arquivos
MDev/
├── index.html
├── style.css
├── gradient.png   (opcional)
└── assets/        (imagens e recursos adicionais)

---

## 🚀 Como Executar
1. Certifique-se de que `style.css` e `gradient.png` (se disponível) estão na mesma pasta do `index.html`.  
2. Abra o arquivo `index.html` em qualquer navegador moderno.  
3. É necessária conexão com a internet para carregar os scripts do **Spline** e do **AOS** via CDN.  

---

## 🎯 Objetivo
Este projeto foi criado para:
- Praticar **HTML5 e CSS3** com foco em responsividade.  
- Explorar **efeitos visuais modernos** (Glassmorphism, Dark Mode).  
- Integrar **elementos 3D** e **animações fluidas** em uma landing page.
